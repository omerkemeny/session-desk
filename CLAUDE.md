# Session Desk: notes for working on the code

Local web app that shows the user's Claude Code sessions as a pixel garden and opens each one as a live CLI in a sidebar.
Server: Python package `desk/`, started by `server.py`. Page: `web/`, native ES modules and plain CSS. No build step, no dependencies.

## Repo map

Server (`desk/`):
- `server.py`: entry point; calls `desk.app.main()`.
- `app.py`: threaded server on 127.0.0.1, reload check before each request, clean SIGTERM/SIGINT shutdown that ends page terminals, replies and the stats worker.
- `config.py`: data folder (`DESK_CLAUDE_DIR`), `PORT`, CLI path (`DESK_CLAUDE_BIN`), page token, stats cache path. Read once at start.
- `transcripts.py`: the only module that knows the transcript, live-process registry and subagent file formats; defensive reads plus the format self-check behind `formatWarnings`/`formatNotes`; reads only appended bytes of recent transcripts (bounded parse-state cache) and counts tolerated anomalies in `formatChecked.anomalies`.
- `summaries.py`: list views kept on disk between runs (`<stats cache>-summaries.json`), keyed by path, mtime, size and inode; versioned, code-hashed, written through `durable.py`.
- `sessions.py`: session summaries, titles, live status (busy wins), `behind`/`also`, running subagents, whole transcripts for the sidebar.
- `stats.py`: Stats panel numbers, counted in a short-lived worker process (`python -m desk.stats`) that updates the cache file (synced temp file + rename); the server keeps only the result. Counts and ids only; day boundaries in `IL`.
- `terms.py`: page terminals (`claude --resume` in a pseudo-terminal) and quick replies (`claude -p --resume`). Never reloaded.
- `termhost.py`: terminal host process (`python -m desk.termhost`); owns page terminals and their output logs, versioned JSON lines on a 0600 Unix socket in the 0700 `.desk-run*` folder, same-user peers only. When the run-folder socket path is too long, the socket lives in a random 0700 temp folder named in `<run>/termhost.sockdir`; only the host creates it and a clean exit removes it. `hello` carries `codeVersion` and `peerCheck`; the host rotates `termhost.log` under its lock and reaps a CLI's exit directly. `ctl.py`: `start`/`stop`/`restart`/`status`/`stop-terminals`, pid and log files.
- Terminal exit codes: the CLI's own, 128 + signal (129 hang-up, which is what End terminal sends), -1 only when a terminal was lost; a server restart mid-stream sends no exit event. A starting host sweeps dead `desk-<uid>-*` socket folders; servers take `<run>/open.lock` while checking, replacing or opening in the host.
- `events.py`: change feed behind `/api/events` (one shared thread, at most 8 listeners); checks recent and live transcripts each second, all of them every `FULL` seconds or when a folder changes.
- `watch.py`: kqueue folder and file notifications for the change feed (at most 400 watches; `DESK_WATCH=0` turns them off). The feed wakes on them where available, else on the 1 s timed scan, which stays as a safety net; at most one change event per 300 ms per listener, preceded by a `sessions` event naming the changed ids.
- `liveness.py`: the change feed's cheap view of live processes: registry re-read only on change, signal 0 plus a native start-time token, `ps` only for a new or changed pid (re-checked every 300 s); subagents re-listed only when their files change. Equals `sessions.holders()`/`helpers()`. `app.py` accepts no new connection while fewer than `FD_SPARE` (32) descriptors are free, and a taken port prints the running server's URL and exits 1; watches get at most `min(400, (limit - 160) / 2)` descriptors (health `fds`).
- `firstrun.py`: health `setup` (dataDir, sessions, cli, stateDir, hint), cached 5 s; `ok` needs dataDir and stateDir ok; the start line and doctor print the same hint. `memprobe.py`: `DESK_TRACEMALLOC=1` adds `memTop` (ten largest allocation sites) to health. `server.py` imports only os/sys and checks Python 3.9 first; any failure prints one line with a log path (`DESK_DEBUG=1` shows the traceback). One server per state and data folder (the foreground server takes `ctl.lock` and checks the pid record); on a read-only state folder the foreground server runs with page terminals off and caches in a temp folder, and `start` refuses with one sentence. Terminal open and quick reply refuse before spawning when the CLI is missing. `doctor` marks are ok / warn / FAIL; exit 1 only on FAIL.
- Scale since round 8: `summaries.py` also keeps the list index, one small entry per transcript (key, automated, shown, continuedIn) with no count bound, saved in the same file; `sessions.py` walks per-class sorted lists over it (`_order`) and reads full views only for listed rows; `sessions(keys=, hold=)` and `sessions_for(ids, keys=, hold=, settled=True)` take the feed's file keys and holders (`events.list_inputs()`, passed by `web.feed_args` when the feed is fresh) so the list need not stat every file. Watches go to live transcripts first, then their registry files, recent transcripts, the registry and projects folders, project folders, subagent paths, older transcripts; the cap is `min(4096, soft limit / 4, (soft limit - 160) / 2)`; unwatched transcripts are stat-ed by a rotating pass within about a second (`ROTATE_MAX` a second at most). No `select()` on server sockets: descriptors above 1024 are normal (`web.py` uses `poll`).
- Data since round 9: kept transcript rows are slim (no bodies: the fields the rules read, list facts, and the line's offset); the list reads only its facts and the sidebar reads shown rows again by offset; a file cut or rewritten under its index raises `Stale` and is read whole once; `tests/test_slim.py` compares against `SLIM = False` (whole rows) on every fixture and 3,000 random trees. Kept state is about 0.27 times the file's text. Rows carry `copies` (live programs holding the session).
- Data since round 10: each kept parse state carries a `_Memo` (conversation walk, recovery indexes, compacted maps, elsewhere counts) that an append extends; it rebuilds whole on a duplicate uuid, compaction, a row named earlier as a missing parent, an end row on another branch, a rewind, a new root, a bridged walk, or no checkpoint (`tests/test_slim.py` asserts each, plus line-by-line growth against `SLIM = False`). `sessions._folds` (`FOLD_MAX` 8) folds only appended rows into the list summary and the sidebar. Errors print 10 lines whole then `… +N line(s)`; an unanswered last call gets the Interrupted line when the session is not live. Health `formatChecked.filesKnown` sits beside the files read this run. `messages.py` holds every setup sentence in one table (`CORE` per state, `LEAD` per place; health `setup.hint` is `CORE` exactly; never reloaded); `tests/test_messages.py` walks every state through every place. Health `setup.warming` is true until the first list is built. The change feed checks unwatched transcripts changed in the last 3 days (at most 2,000) every second and older ones with the rest of `ROTATE_MAX`.
- `web.py`: request handler, guards, routes, static files, `health()`.
- `reloader.py`: hot reload of changed modules.
- `doctor.py`: `python3 server.py doctor`, a read-only pass/fail list (Python, CLI, data folder, run folder, port, stats cache, terminal host); exit 0/1.
- `durable.py`: one-writer atomic file writes (folder lock, synced temp file, rename, folder sync, mode 0600); used by the stats cache, `server.json` and `termhost.pid`. Never reloaded.

Page (`web/`):

## Rules that keep it healthy

- Python standard library only. No build step, no bundler, no npm packages; the terminal library stays bundled in `web/vendor/`, never a CDN.
- ES modules with explicit imports. Nothing on `window` except `desk` (debug helpers); the shell's `DESK_TOKEN` and xterm's globals are the only other allowed names (the smoke test checks this).
- Transcript-format knowledge lives only in `desk/transcripts.py`. Other modules use its accessors, never raw JSON keys.
- Never make `termhost.py` or `ctl.py` reloadable. Any change to host ops or fields bumps `termhost.PROTOCOL`; `hello` and `stop` keep their shape.
- Never make `terms.py` or `config.py` reloadable: terminals, the token and the port live there. Fixed modules reach reloadable ones by module attribute (`transcripts.find(...)`), never `from .x import name`.
- Never write into `~/.claude`; changes to sessions go through the `claude` CLI. The only files written are the stats cache and its summary cache (`.stats-cache*-summaries.json`) beside `server.py`, plus the run folder `.desk-run*`.
- Never accept the CLI's folder-trust prompt for the user.
- Every new route must keep these guards:
  - Host header must be `127.0.0.1:<port>` or `localhost:<port>` (both `do_GET` and `do_POST`). Bind to 127.0.0.1 only, never 0.0.0.0.
  - Writes are POST only and need the same Origin and the `X-Desk-Token` header (`secrets.compare_digest`); add the route to `WRITES` and validate `id`.
  - GET routes are read-only: no CLI runs, no terminal input, no file writes. A GET with `Sec-Fetch-Site` cross-site or same-site gets 403, except a document navigation to `/`.
  - Every answer carries `X-Frame-Options: DENY`, `frame-ancestors 'none'`, `nosniff` and `no-referrer`. POST bodies are at most 100 KB (413), at most 16 terminal streams run at once (503), requests time out after 30 s.
  - The terminal host validates every field and keeps its own cap (`HARD_MAX` 16); a CLI inherits no file descriptors beyond 0-2; the peer check fails closed on Linux and macOS. `server.json` is versioned (`v`) and trusted only when the pid's start time and health `started` both match.
  - `/legend.html` and `/gallery.html` are a fixed list of read-only pages served without the token shell; no other `.html` is served.
  - Static files: only under `web/`, extension in `TYPES`, no empty or dot segments, no dotfiles, no backslash or NUL, must resolve inside `web/` after `realpath`; `/api/*` is never static; `/vendor/` serves the fixed `VENDOR` list only.

## Hot reload

- Page files are read from disk on every request (`no-store`): edits under `web/` apply on a browser reload.
- `desk/*.py` except `__init__`, `config`, `terms`, `reloader`, `app` (see `FIXED`) re-run from source on the next request (checked at most once a second), with every module after them in import order. New modules are found too. Open terminals and the page token survive.
- A broken edit keeps the old code serving; `/api/health` shows `reloadError`.
- `webVersion` in health is the newest time of the served `web/` files (checked at most every 5 s); the page shows an "updated · reload" pill when it or `codeVersion` moves. A terminal host whose code differs from the server's is reported in health (`termhost.older`, `note`) and `status`; with no live terminals it is replaced at the next terminal open.
- Edits to a `FIXED` module, or to `server.py`, need a restart. `restartNeeded` in health lists the changed `FIXED` files (`server.py` is not listed). `codeVersion` is the newest source time of the loaded code and `reloads` counts reloads, so you can see whether an edit loaded.
- Restarting keeps page terminals (they live in the terminal host); `python3 server.py restart` is safe to run from a page terminal. Changing `termhost.py` needs `stop-terminals` and a bump of `PROTOCOL`.

## Preview without the user's data

- Demo page only: `python3 tools/dev_static.py` and open http://[::1]:8798 (example data, no server calls).
- Real server on invented data: copy the fixtures and use another port, never 8765:
  `cp -R tests/fixtures/home /tmp/desk-home && DESK_CLAUDE_DIR=/tmp/desk-home PORT=8790 python3 server.py`
  The fixtures have no live processes, so every session lists as Resting and the garden is empty. Their folders do not exist, so terminals and replies refuse to start. The stats cache goes to `.stats-cache-<hash>.json`, gitignored.
- To avoid spawning the real CLI in a test, point `DESK_CLAUDE_BIN` at a stub.

## Privacy

- Never paste transcript text, prompts, replies or session titles into chats, logs, commits, issues or screenshots. Use counts, field names and the fixtures.
- When a format check fails on real data, inspect keys and types only, never values.
- Never package or share `.stats-cache*` files, the summary cache included; they describe the user's usage.

## Conventions

- One-line docstring per Python function, one-line comment per JS function or block; no longer explanations in code.
- Named constants at the top of a module with a short trailing comment (`RECENT`, `MAX_TERMS`, `STATS_TTL`).
- JS files start with `// @ts-check` and a one-line purpose comment; types via JSDoc from `src/types.js`.
- Commit messages: at most two short sentences. No authorship, tool or attribution lines anywhere.

## Known limits

- macOS and Linux only (`pty`, `fcntl`, `termios`).
- A session also open in the desktop app or another terminal is two live copies; the page warns (`also`) and offers Reload terminal (`behind`).
- The session file format is not a public contract. After a Claude Code update, check `formatWarnings` and fix `desk/transcripts.py`.
- A user's SessionEnd hook runs after every quick reply and every page terminal end or reload.
